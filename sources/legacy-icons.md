# Legacy icon provenance

These originals were migrated from `arkpedia/arkpedia` at commit `d4f4a16d92e7b80c0b73c11724972982056f3821`. The WebP files are lossless conversions.

- `originals/faction-icons/Chiave's Gang.png` is the unmodified game camp logo retrieved from [ArknightsAssets](https://github.com/ArknightsAssets/ArknightsAssets/blob/c0be4e4428f79c7e87c6889067a6906361ae979b/assets/torappu/dynamicassets/arts/camplogo/logo_chiave.png).
- `originals/essential-icons/Potential 1.png` is the source used by Arkpedia before the public asset split. Its earlier upstream provenance was not recorded, so it is not claimed more specifically here.

The game supplies the **Rhodes Island** emblem for [Laios's Party](https://github.com/ArknightsAssets/ArknightsAssets/blob/c0be4e4428f79c7e87c6889067a6906361ae979b/assets/torappu/dynamicassets/arts/camplogo/linkage/logo_laios.png) and [Ave Mujica](https://github.com/ArknightsAssets/ArknightsAssets2/blob/41244df3be898a4263ded6367b1b74253f7a2c45/assets/dyn/arts/camplogo/linkage/logo_mujica.png). Arkpedia aliases those factions to the existing Rhodes Island asset rather than storing duplicate or invented emblems.
